# 拼豆

一个可直接上线的浏览器拼豆工作台，面向拼豆玩家、手作门店和定制卖家。原图只在用户浏览器中处理，无需登录，也不经过服务端。

## 完整闭环

- 上传 PNG、JPG、WebP 或 GIF，透明通道会被保留
- 原图区域取样，不先压成低分辨率图片；支持主体色 / 平均色两种取样
- 输出 29、58 或 16–100 格宽度，并可保持原图比例生成 N × M 图纸
- 自动去背景先于颜色压缩，背景不占颜色预算；容差可调
- 291 色完整色表，支持 MARD、COCO、漫漫、盼盼、咪小窝五个品牌
- 库存驱动取色：只使用用户实际拥有的颜色，缺色自动匹配最近库存色
- 旋转、水平 / 垂直翻转、裁切适配与裁切焦点
- 画笔、单格擦除、同色连通区域擦除、吸色、全局替换、撤销和重做
- 可解释的本地中文规则助手；无法识别的指令不会伪装成已经执行
- 本地自动保存与恢复；工程 JSON、逐格矩阵 CSV 可导入和导出
- 导出带行列坐标、5 格辅助线、29 格分板线、色号与图例的施工 PNG
- 导出实际用豆采购 CSV，并自动给出 8% 备料余量
- 专注制作模式：按颜色筛选、逐格完成、计时和进度持久化
- 编辑预览、统计、采购清单和所有导出始终来自同一份当前矩阵

## 本地运行

要求 Node.js 22.13 或更高版本。

    npm install
    npm run dev

完整验收：

    npm run lint
    npm test

npm test 会执行生产构建、服务端渲染检查、完整色表检查以及关键数据闭环约束。

## 部署

项目使用 Vinext / React 19，并已配置 OpenAI Sites。运行：

    npm run build

构建产物位于 dist/，.openai/hosting.json 保存 Sites 项目标识。

## 产品边界

- 中文修改是本地、可解释的规则解析，不等于云端多模态模型或人物部位级语义编辑。
- 去背景采用边缘连通色识别；主体和背景颜色接近时，应降低容差或用区域擦除手动修正。
- 品牌色号来自开源对照表。屏幕、光线、批次和厂商色卡更新都会造成偏差，正式制作前必须对照实物色卡。
- 当前版本不包含门店实时库存、账号云同步、多人协作、支付或自动摆豆硬件控制。

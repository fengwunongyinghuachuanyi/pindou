# 豆搭 · 照片转拼豆图纸

一个面向拼豆玩家、手作门店和定制卖家的浏览器应用。原图仅在本机浏览器中处理，无需登录。

## 已实现

- 上传 JPG、PNG 或 WebP，自动转为规则拼豆网格
- 29×29 与 58×58 方案对比，同时估算成品尺寸、用豆量、时长和材料费
- 颜色数量控制、杂色合并、边缘背景清理和两种裁切适配方式
- 用中文指令调整尺寸、背景、色数、明暗、饱和度与轮廓
- 画笔、橡皮、取色、整色替换、撤销和重做
- MARD、COCO、漫漫色号切换和用豆统计
- 导出带网格与色号的 PNG 图纸、CSV 采购清单，或通过浏览器存为 PDF
- “专心拼豆”模式，可逐格标记实体制作进度

```

```

## 当前边界

- 中文修改是本地规则驱动的可用原型，能处理尺寸、背景、颜色和轮廓类要求，不等于已具备人物或宠物部位级语义理解。
- 背景清理使用边缘连通色填充；复杂场景仍可能需要手动修图。
- 品牌色号映射为产品原型数据；颜色会受屏幕、光线和豆子批次影响，正式制作前应对照品牌最新实物色卡。
- 原型未包含门店实时库存、预约、多人协作或自动摆豆硬件。
